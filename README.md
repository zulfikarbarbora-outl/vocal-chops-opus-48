# vocal-chops-opus-48

Short sung notes and vocal phrases (ahh, mmm, hmm, sustained pitches) suitable for sequencing into vocal chops. Sourced from Freesound packs 39031 (Repeal sung notes, CC-BY) + 29765 (hugo_nl janie_joelle vocals, CC-BY).

## About

This repo holds **48 kbps Opus previews** for fast streaming in the web DAW.
Opus at 48k delivers near-CD quality at ~35% the size of MP3 128k.

- **Library**: Vocal Chops & Phrases
- **Files**: 10 Opus previews
- **Bitrate**: 48 kbps VBR
- **Container**: Ogg Opus (.opus)
- **License**: CC-BY-4.0
- **Source**: https://freesound.org/people/Repeal/packs/39031/
- **Branch**: `main`
